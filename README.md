# Student Club Management System

A Python-based application for managing student club members through a command-line interface.

## Features

- Add new members with name and age validation.
- Display all registered members.
- Search for members by ID.
- Update member information.
- Delete members.
- Display statistics by activity.
- Save and load member data using file handling.

## Concepts Used

- Object-Oriented Programming (OOP)
- Classes and Inheritance
- Encapsulation
- Lists and Loops
- Input Validation
- File Handling

## Technologies

- Python 3

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

   `python main.py`

## Note

This project was developed as a practical exercise in Python programming and object-oriented design.
